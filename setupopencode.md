# Setup OpenCode

Follow these steps in order. Each command is in its own box - use the copy button in the top-right of the box.

## 1. Install Node.js

Download and install from here:

- <https://nodejs.org/en/download>

> OpenCode needs Node.js installed first.

## 2. Install OpenCode

Pick one based on your OS. Copy and run one command:

**Mac / Linux:**

```bash
curl -fsSL https://opencode.ai/install | bash
```

**Windows (PowerShell):**

```powershell
npm install -g opencode-ai
```

## 3. Verify OpenCode works in your editor / terminal

Copy and run:

```bash
opencode --version
```

> If you see a version number, you're good. If not, restart your terminal and try again.

## 4. Open OpenCode in your terminal

Copy and run:

```bash
opencode
```

> Run this inside your project folder.
