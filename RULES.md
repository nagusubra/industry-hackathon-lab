# Hackathon Rules — IEEE YP Industry Hackathon (Oct 2–4, 2026)

1. Teams of **2–5 members**; all members must register at https://events.vtools.ieee.org/m/572071.
2. **One submission per team** as a GitHub Issue via the Hackathon Submission form, within Fri Oct 2 5:00 PM MDT → Sun Oct 4 12:00 PM MDT (grace to 12:10 PM MDT).
3. Project repo must be **public** with source, README, and run instructions (`requirements.txt`/`environment.yml`/`Dockerfile` recommended).
4. Work must be original and built during the event (prepared case starters and public datasets allowed; cite all data sources).
5. Submissions are **public**; do not post secrets/API keys. Broken posts may be deleted by organizers on request for resubmission.
6. Deadline is enforced by issue `created_at`; threads lock at close. Late (`>12:10 PM MDT`) eligibility is at judges' discretion.
7. Judging per `JUDGING_RUBRIC.md` (100 pts). Winners announced Sun Oct 4, 4:00 PM MDT.
8. Follow the Code of Conduct. Contact: nagusubra@ieee.org.
